# 姐妹省钱打卡 PWA

这是一个手机优先的 PWA 省钱打卡网页，支持妹妹/姐姐双身份、本地记账、奶茶规则、每周/月统计、周边盲盒统计和 Excel 导入导出。

## PWA 功能
- 可添加到 iPhone / 安卓主屏幕
- 独立窗口启动，体验接近 App
- 核心页面和本地记账支持离线使用
- 数据仍保存在各自设备浏览器的 localStorage 中，键名：`sister-saving-v1`
- Excel 导入/导出继续使用 SheetJS CDN；首次加载该组件需要联网，成功加载后浏览器/PWA 会尽量缓存

## 部署要求
PWA 的 Service Worker 不能通过直接双击 `index.html` 的 `file://` 方式启用。请部署到 HTTPS 网站（例如 GitHub Pages / Cloudflare Pages / Netlify），或者开发时通过 localhost 运行。

### 本地测试
在项目目录运行：

```bash
python3 -m http.server 8080
```

然后电脑访问 `http://localhost:8080`。手机测试时建议部署到 HTTPS 地址。

## iPhone 安装
1. 用 Safari 打开部署后的 HTTPS 地址
2. 点击“分享”
3. 选择“添加到主屏幕”
4. 从桌面图标启动

## 安卓安装
1. 用 Chrome 打开部署后的 HTTPS 地址
2. 点击网页中的“安装”提示，或浏览器菜单中的“安装应用 / 添加到主屏幕”
3. 从桌面图标启动

## 数据同步
两个人的数据默认互不自动同步。需要阶段对齐时：一方导出 Excel → 发给另一方 → 另一方“导入并合并”，网页会按身份合并并自动去重。

## 每日额度与消费日历
- 所有金额显示两位小数，消费合计以分计算；日期使用设备本地日期。
- 首页可按妹妹/姐姐设置每日额度和生效日期，允许 0 元，历史额度保留。改动过去生效日会重新计算该日起、下次设置前的结果。
- 统计页按周一至周日相加得到周额度，可选择日期查看往周。整周剩余额度包含未来日期；净结余仅计算已记录或确认零消费、且已设额度的日期，当天为暂计，不等于实际存款。
- 消费日历支持切月、每日明细、编辑删除与零消费确认。🧋 代表奶茶/咖啡类别或有奶茶杯数；✅ 代表有记录且在额度内；🔺 代表超支。漏记和未来日期不会自动达标。
- Excel 备份包含“额度设置”和“零消费确认”，兼容旧版备份。导入额度仅补充不存在的生效日期，同日现有额度优先。

## 固定开支与 Excel 同步
- 固定开支是独立类别，可在底部“固定”查看指定月份、编辑或删除明细。月总消费和周总消费包含固定开支；每日消费、每日额度、周预算结余及日历达标统计排除固定开支。
- 只有固定开支的日期不会自动算作日常消费已完成，可另行确认“日常零消费”。
- Excel 的“每日记录”仍是完整原始账单，包含固定开支。另有“固定开支明细”和“月度消费汇总”供查看，导入不会重复读取这些展示表。两人的账单、存款、额度和零消费确认均保留。
- 新版新增账单使用唯一 ID，修改记录写入更新时间；同步同一 ID 时较新的版本优先。新增“删除记录”工作表，避免重新导入旧备份使已同步删除的账单复活。请双方更新到新版后互传完整 Excel。无时间戳的旧版冲突记录保持原先保守合并规则。
- 同日额度冲突仍保留本机设置；每周实际存款保持原先取较大值的合并规则。设备之间仍需手动交换 Excel，不是自动云同步。

## 多选分类与文字导入（2026-11）
- 一级分类：饮食、交通、网购、奶茶、固定开支、日用品、周边盲盒。一笔可选多个一级分类，每个类别可选二级分类。总消费按账单只计一次，标签统计可以交叉，不可直接相加。包含固定开支标签的整笔账单不占每日/每周额度。
- 旧账单无需重导入：早餐/午餐/晚餐/零食/社交归入饮食，娱乐/其他归入日用品，旧代码保留为二级分类；未知旧分类也保留。旧 Excel 仍可导入。新版 Excel 新增一级和二级类别代码列，完整保留多选信息，须使用新版网页导入。
- 入口：记账 → 粘贴文字，批量记账。选择年份和账本，粘贴带日期标题及缩进条目的文本，解析后逐笔核对日期、金额、备注、类别和杯数，确认或跳过，最后统一入账。
- 支持 `-` / `*` Markdown 列表、`M.D`、完整 `YYYY-MM-DD` 日期；无缩进的纯 `8.29` 视为日期标题，缩进的 `8.29` 视为金额。未识别行会给出行号，需要修正后才能创建队列。跨年按选择的方向推算，建议核对或明确填写年份。
- 解析和逐笔分类只写独立草稿 `sister-saving-text-draft-v1`，不改正式账单。草稿保存于当前设备浏览器，刷新后可继续；队列锁定目标身份，不跟随顶部身份切换。最终提交失败会回退正式账单并保留草稿。
- 重复记录和已删除的同一文字记录会提示。确实是另一笔时可明确勾选仍然导入。同一天多条完全相同的记录按出现次数区分。文字导入标识会随 Excel 保存，导出再导入后仍可识别同一批文字。
- 来源为“别人买单”、混合消费等说明不会被猜测为退款、拆单或减免，原文作为备注保留，由你逐笔核对。

### 测试
运行 `node --test tests/ledger-tools.test.cjs` 检查解析、日期、类别迁移及导入标识规则。

## 界面整理
- 文字批量导入移至“姐妹”页的数据备份下方；导入草稿不受入口调整影响。
- 记账页默认只显示常用字段，二级分类及名称、备注、冲动消费可展开，编辑时自动展开详情。
- 统计、姐妹页分别支持上月/下月、指定月份和回到本月。统计页的月份同步月度金额、分类汇总与日历，周结算仍独立按所选周计算。
- 姐妹页月存款按周开始日期所属月份汇总，避免将累计存款标为月存款。
- 统计页改为月度总览优先，日历明细默认折叠。
